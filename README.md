# miWebPersonal — repositorio archivado

Este repositorio contiene la **primera versión** del sitio personal de
[Duvan Yair Arciniegas](https://github.com/axchisan), desarrollada entre
**septiembre de 2025 y junio de 2026**.

## El proyecto continúa en otro sitio

> ### → **[axchisan/axchisan.com](https://github.com/axchisan/axchisan.com)**

Toda esta historia —los 42 commits de este repositorio— fue **injertada** en el
repositorio nuevo, de modo que allí vive el proceso completo del proyecto de
forma lineal y sin cortes, desde el primer commit de septiembre de 2025 hasta
hoy. No se perdió nada; simplemente dejó de estar aquí.

Este repositorio queda archivado como referencia. No recibe cambios.

## Qué fue

Sitio personal con panel de administración propio, construido con Next.js,
Prisma y PostgreSQL, desplegado en un VPS con Docker y Coolify. Incluía gestión
de proyectos, blog, mensajes de contacto, subida de archivos y métricas.

Se dio de baja al vencer el VPS. La versión actual corre sobre infraestructura
serverless con cuota gratuita permanente.
